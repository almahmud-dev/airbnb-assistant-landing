# Airbnb Assistant — Property Management Landing Page

A modern, fully responsive landing page for an Airbnb Property Management
Assistant service. Built with Next.js 16.2 and Tailwind CSS.

![Preview](public/preview.png)

## 🔗 Live Demo

[View Live →](https://airbnb-assistant-landing.vercel.app)

## ✨ Features

- Responsive design (Mobile, Tablet, Desktop)
- Pricing plans section
- Services & tools showcase
- FAQ accordion
- Partner integrations
- Smooth animations

## 🛠️ Tech Stack

- Next.js 16.2 (App Router)
- JavaScript (JSX)
- Tailwind CSS
- Framer Motion

## 🚀 Getting Started

Clone the repository:

git clone https://github.com/almahmud-dev/airbnb-assistant-landing.git

Install dependencies:

npm install

Run the development server:

npm run dev

Open http://localhost:3000 in your browser.
